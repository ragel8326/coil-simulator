이 폴더는 고정 25→10 Oe 목표 직선 버전(coil-bench-fixedline)을 복사해 "실험 조건 (As-built)" 탭을 더한 버전 (원본: coil-bench)

# 구배 코일 설계 벤치

자성재료 Project 1 — 공심 코일 두 개로 25 Oe → 10 Oe 선형 자기장 구배를 설계·최적화하고,
실측값과 비교해 오차 원인을 정량화하는 도구입니다.

편차를 계산하는 비교 직선은 설계가 실제로 만드는 `x=0`과 `x=d`의 자기장을 잇습니다.
25 Oe와 10 Oe는 그 직선의 고정 좌표가 아니라, 각 끝점에 적용되는 공칭 요구값(±1 Oe)입니다.
최적화는 직선성과 끝점 요구를 함께 보며, 끝점 허용범위 밖에서는 연속적으로 커지는 벌점을 사용합니다.
기본 목적함수는 실제 끝점 사이 낙폭으로 나눈 무차원 MSE이므로 전류 크기를 낮추는 편법에 영향을 받지 않습니다.
러너는 과제 조건과 2026-09-14 팀 결정에 따라 전류를 기본 1 A로 고정하며, Oe 단위 최대편차는 보고·공차 순위용으로 별도 유지합니다.

빌드 과정도 의존성도 없는 정적 HTML 파일 하나입니다. `index.html` 을 브라우저로 열면 바로 동작합니다.

## 모델

각 권선 한 턴을 반경 `r`, 축 위치 `x_t` 의 원형 루프로 보고 축상 자기장을 합산합니다.

    H(x) = Σ  s · I · r² / [ 2 (r² + (x − x_t)²)^{3/2} ]        [A/m]

- `s` = 감는 방향 (+1 / −1)
- 1 Oe = 79.5774715 A/m
- 구리 비저항 1.68 × 10⁻⁸ Ω·m

턴 위치는 인덱스로 직접 계산합니다(부동소수점 누적 금지).
`Model 1` 은 모든 턴을 평균 반경·코일 중심 한 점에 몰아넣은 얇은 코일 근사,
`Model 2` 는 층수와 층당 턴 수를 반영한 실제 권선 모델입니다.

해석식은 Biot–Savart 직접 수치적분과 상대오차 10⁻¹⁶ 수준까지 대조해 검증했습니다.

## 기능

| 탭 | 내용 |
|---|---|
| 계산 | 거리별 자기장, Model 1 / Model 2 비교, 코일별 기여 분리, 변곡점 표시, 발열·저항·구리선 길이·보빈 치수, 요구사항 자동 판정 |
| 최적화 | 차분진화(DE)로 반경·권선수·간격·측정창 탐색. 코일2 감는 방향 자동 탐색, 최소 측정창 길이를 제약으로 처리 |
| 민감도 · 공차 | 중심차분 기반 민감도 분석, 몬테카를로 공차 밴드 |
| 측정 데이터 | 반복 측정 → 평균·STDEV, 가중 최소자승, Levenberg–Marquardt 비선형 최소자승으로 실제 코일 파라미터 역산 + 파라미터 상관 경고 |
| 실험 조건 (As-built) | 9/29 실험의 실제 좌표·권선 조건으로 계산한 모델을 실측과 겹쳐 비교 (아래 절 참고) |

## 쓰이는 수치해석 기법

- 이분법 근 찾기 — 변곡점 정밀화
- 중심차분 수치미분 — 민감도 분석, 곡률 0 지점 탐색
- 가중 최소자승 — STDEV 를 가중치로 쓴 직선 피팅
- Levenberg–Marquardt 비선형 최소자승 — 실측에서 유효 반경·진폭 계수·프로브 영점 역산,
  공분산 `(JᵀWJ)⁻¹` 에서 표준오차와 파라미터 상관계수 산출
- 차분진화(DE) — 전역 최적화
- 몬테카를로 — 제작 공차 전파

## DE 하이퍼파라미터 선택 근거

`runOptimize()`의 차분진화(DE)는 개체군 크기(population), 스케일 계수 `F`,
교차율 `CR`을 코드 상수로 고정해 쓴다. Storn & Price(1997) 원 논문의 권장 범위
(개체군 5D~10D, F 0.4~1.0, CR은 문제에 따라 0.1 또는 0.9~1.0)를 출발점으로 삼되,
이 프로젝트의 목적함수(기본 코일 설계값, `objsel=max`, 150세대, 코일2 방향
auto)에 대해 F·CR·개체군 배수를 하나씩 바꿔가며(one-factor-at-a-time) 30회씩
반복 실행해 최종 Max deviation의 평균·표준편차를 비교했다. 개체군 배수와
CR은 최종 채택값(F=0.5, CR=1.0, pop=8×D)을 다른 두 값에 고정한 채 스윕했다.

전체 그리드 서치는 아니므로, 세 하이퍼파라미터의 상호작용까지는 확인하지
못했다는 한계가 있다.

**F 스윕** (CR=1.0, pop=8×D 고정)

| F | 평균 | 표준편차 | 최소 | 최대 |
|---|---|---|---|---|
| 0.3 | 0.8043 | 0.0917 | 0.7429 | 1.1274 |
| **0.5** | **0.7550** | **0.0119** | 0.7359 | 0.7831 |
| 0.7 | 0.7721 | 0.0169 | 0.7411 | 0.8026 |
| 0.9 | 0.7816 | 0.0183 | 0.7470 | 0.8205 |
| 1.0 | 0.7893 | 0.0480 | 0.7399 | 0.9621 |

F=0.5가 평균·표준편차 모두 최저인 뚜렷한 최적점. 너무 작으면(0.3) 탐색이
불안정해지고(표준편차 0.09, 최악값 1.13까지 튐), 너무 크면(1.0)도 다시
불안정해진다(표준편차 0.048).

**CR 스윕** (F=0.5, pop=8×D 고정)

| CR | 평균 | 표준편차 | 최소 | 최대 |
|---|---|---|---|---|
| 0.1 | 0.8625 | 0.0429 | 0.7756 | 0.9607 |
| 0.3 | 0.8472 | 0.0440 | 0.7791 | 0.9678 |
| 0.5 | 0.8340 | 0.0280 | 0.7556 | 0.8867 |
| 0.7 | 0.8018 | 0.0178 | 0.7747 | 0.8452 |
| 0.9 | 0.7635 | 0.0147 | 0.7380 | 0.7944 |
| **1.0** | **0.7555** | **0.0140** | 0.7322 | 0.7852 |

CR을 올릴수록 평균·표준편차가 꾸준히 개선되고 CR=1.0에서 가장 좋다.

**개체군 배수 스윕** (F=0.5, CR=1.0 고정)

| 배수 | NPOP | 평균 | 표준편차 | 최소 | 최대 |
|---|---|---|---|---|---|
| 4×D | 24 | 0.7761 | 0.0640 | 0.7305 | 1.0997 |
| 6×D | 30 | 0.7632 | 0.0192 | 0.7272 | 0.8121 |
| **8×D** | **40** | **0.7583** | **0.0146** | 0.7326 | 0.7871 |
| 10×D | 50 | 0.7542 | 0.0115 | 0.7387 | 0.7909 |
| 12×D | 60 | 0.7537 | 0.0104 | 0.7273 | 0.7736 |

(D=5, 기본 체크된 최적화 변수: 코일1 반경·턴/층·층수, 코일2 턴/층, 간격 기준)

배수가 커질수록 계속 좋아지지만 8×D 이후로는 개선 폭이 작아진다(수확체감).
8×D를 성능·속도 절충점으로 채택했다.

**결론**: 세 스윕 모두 최종 채택값(F=0.5, CR=1.0, pop=8×D)이 원 논문의
권장 범위 안에 있으면서, 이 프로젝트의 목적함수에서는 논문 기본값에 가까운
설정(F=0.7, CR=0.9, pop=6×D)보다 평균·산포 양쪽에서 더 나은 결과를 보였다.

## 실험 조건 (As-built) 탭

다른 탭은 설계 조건(코일 중심 기준 좌표, 균일 권선, 코일 중심 간 거리 d)으로 계산합니다.
이 탭은 9/29 실험을 **실제로 한 조건 그대로** 계산해서 실측값과 겹쳐 봅니다.
다른 탭의 입력값·상태는 쓰지 않고, 탭이 열려 있는 동안 왼쪽 설계 파라미터 레일은 숨겨집니다.

### 좌표계 (단위 mm)

가우스미터 프로브가 코일 안으로 들어가지 못해 두 코일 **사이**에서만 측정했기 때문에, 원점이 코일 중심이 아닙니다.

- **x = 0 : 코일1 플랜지 중 코일2를 향한 면의 바깥면**
- x = G : 코일2 플랜지 중 코일1을 향한 면의 바깥면 (G = 두 플랜지 바깥면 사이 거리, 실험값 40)
- +x 방향 = 코일1 → 코일2
- 목표 직선: x = 0 에서 25 Oe → x = G 에서 10 Oe

따라서 코일1 권선은 x ∈ [−(t+W1), −t] = [−24, −4], 코일2 권선 영역은 [G+t, G+t+W2] = [44, 54] 입니다.

### 턴 배치

- 코일1: 칸(축 방향 column) m1개, 칸 폭 W1/m1. 칸 i(0 = 바깥쪽, m1−1 = 코일2 쪽), 층 j 의 턴은
  `r = R1b + p1·(j+0.5)`, `x = −(t+W1) + (W1/m1)·(i+0.5)`.
  - 균일: 칸마다 floor(N1/m1)층, 남는 턴은 칸 (k·7) mod m1 = 0, 7, 14, 21, 28, … 순서로 1층씩.
  - 한쪽 쏠림: 칸 i 의 층수 = round(a + (b−a)·i/(m1−1)) (방향 토글로 좌우 반전), 합이 N1 이 되도록 같은 순서로 ±1 조정.
- 코일2: 1층, 반경 R2b + dw/2, 턴 k 의 x = 시작점 + dw·(k+0.5). 시작점은 코일1 쪽 플랜지에 붙임 = G+t,
  가운데 = G+t+(W2−N2·dw)/2, 먼 쪽 = G+t+W2−N2·dw.
- 자기장은 COIL-CORE 의 `H_pack`(ρ = 0) 또는 `H_pack_offaxis` 의 Hz(ρ > 0)를 그대로 호출합니다.

### 가정값 (실측하지 않은 값 — 화면에 "가정값" 표시)

| 항목 | 기본값 | 비고 |
|---|---|---|
| 코일1 층 하나 두께 p1 | 0.6 mm | 슬라이더 0.5~1.0. 선경 0.5 mm + 층 사이 틈을 가정 |
| 코일1 층 분포 | 균일 | 실험에서는 코일2 쪽이 두꺼워 보였음 → "한쪽 쏠림 (a=4, b=10, 코일2쪽 두꺼움)"으로 바꿔 비교 가능 |
| 코일2 턴 위치 (보빈 안) | 코일1 쪽 플랜지에 붙임 | 가운데 / 먼 쪽으로 바꿔 비교 가능 |

실험에서 잰 값(기본값): R1b 45, W1 20, t 4, N1 222, m1 31, R2b 22, W2 10, N2 11, dw 0.5, G 40, I 1.0 A (±0.1 A, 발열로 흔들림).

### 지표와 주의

- 전류 추정 `I = Σ(H_model·H_meas) / Σ(H_model²)` (H_model 은 1 A 기준)은 **역산한 추정값이지 측정한 전류가 아닙니다.**
  화면에 그렇게 표시되고, "추정 I 적용" 버튼을 눌렀을 때만 I 칸에 들어갑니다. 기본 표시는 입력한 I 로 계산합니다.
- "직선 이탈" 그래프는 각 곡선에서 자기 자신의 x=0, x=G 값을 이은 직선을 뺀 값입니다. 전체 크기·기울기 차이를 없애고
  휘어진 모양만 비교하려는 것이며, 휨의 깊이 자체는 전류에 비례합니다.
- 측정 CSV 는 `x_mm, reading_1, reading_2, …` 열만 읽고(나머지 열 무시), 평균·표준편차(n−1)는 reading 열로 다시 계산합니다.
  행 순서가 측정 순서(P1, P2, …)입니다.

### 검증

턴 배열 생성·지표 계산은 `index.html` 의 `ASBUILT-CORE-START ~ ASBUILT-CORE-END` 구간에 DOM 없는 순수 함수로 있고,
`runner/asbuilt.mjs` 가 이 구간을 COIL-CORE 와 함께 떼어내 `runner/asbuilt.test.mjs` 로 검사합니다.

    node --test runner/

## 명령줄 최적화

기본값은 `I=1 A`, 무차원 MSE, 치수 격자 0.1 mm, 코일당 200턴, 도선 0.4/0.5 mm입니다.
코일 1 반경을 24 mm로 고정한 일반 탐색은 다음처럼 실행합니다.

    node runner/run.mjs --fix R1=24 --restarts 200

코일 1의 Task-1 충족 권선을 먼저 전수검사하고 나머지 변수만 DE로 찾으려면
`--enumerate-coil1`을 붙입니다. 이 모드는 `--fix R1=...`이 반드시 필요하며,
모든 열거 조합을 한 번 이상 보려면 재시작 횟수가 후보 수(현재 각 굵기 26개) 이상이어야 합니다.

    node runner/run.mjs --fix R1=24 --enumerate-coil1 --restarts 200

비교 실험에는 `--objective max`를 쓸 수 있고, 전류 조건을 바꿔 시험할 때만
`--current 0.8` 또는 기존의 `--fix I=0.8` 경로를 사용합니다.
